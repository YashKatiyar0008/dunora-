# Dunora — 3-minute product keynote script

**Required submission:** Record the browser at the actual public hosted URL. 1920×1080 or 1440×900, 30 fps, cursor visible, clear voiceover, subtitles, no secrets. Official Nexus V2 requires a **2-to-5 minute video**.

| Time | Visual: show actual working product | Narration |
|---|---|---|
| 0:00–0:17 | Dunora login, click “Explore with an instant demo” | “Small businesses don't need another dashboard. They need an accurate answer to one question: which invoices should I act on today, and why?” |
| 0:17–0:37 | Overview: outstanding, overdue, at risk, collections graph | “This is Dunora, an evidence-first revenue operations system. Every figure comes from invoices and recorded payments — not hallucinated predictions.” |
| 0:37–0:59 | Invoices page, customer search, open an invoice | “Here is our single source of truth: due dates, balances and payment references. I can drill into any customer and trace the math.” |
| 0:59–1:22 | Record a **partial** payment using fictional demo reference | “I enter an actual verified transaction reference. The outstanding balance changes immediately, with safeguards against duplicate payments and overpayments.” |
| 1:22–1:44 | Collection Studio priorities and evidence chips | “The prioritized outreach queue tells me why each account ranks highly. It is deterministic and auditable, and disputed invoices are removed automatically.” |
| 1:44–2:06 | Draft reminder; edit text; click approve | “We prepare a contextual message, but a human approves every send. Without real SMTP credentials, we clearly log a simulation — we never pretend an email was delivered.” |
| 2:06–2:23 | Activity log and CSV export | “A persistent audit trail records decisions. Each user only sees their own workspace. The system is built on FastAPI, SQLAlchemy, PostgreSQL and secure cookie sessions.” |
| 2:23–2:45 | Plans & billing, then GitHub architecture/CI tests or brief overlay | “The product has a freemium-to-subscription model, optional real Stripe checkout, a repeatable Docker deployment, and automated accounting and isolation tests.” |
| 2:45–3:00 | Final dashboard and product tagline | “Dunora: stop chasing. Start collecting. Software designed to earn trust first — and recurring revenue next.” |

Use a clearly labeled demo/fictional workspace and no claims about real customers, paid subscriptions, active emails or audited compliance unless independently verified. Include the public app link, repository URL and final recorded video URL in the Devpost form.
